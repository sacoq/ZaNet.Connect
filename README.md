# ZaNet Connect

**3.0.0 — открытый бета-тест**

VPN-клиент ZaNet для Windows и Android. Этот репозиторий содержит готовые релизы и информацию об установке.

## Скачать

- [Windows x64 — установщик MSI](https://github.com/sacoq/ZaNet.Connect/releases/download/v3.0.0/ZaNet-Connect-Windows-x64.msi)
- [Android ARM64 — APK](https://github.com/sacoq/ZaNet.Connect/releases/download/v3.0.0/ZaNet-Connect-Android-arm64.apk)
- [Описание версии и контрольные суммы](https://github.com/sacoq/ZaNet.Connect/releases/tag/v3.0.0)

Для подключения нужна действующая VPN-подписка.

## Что доступно

**Windows:** Xray и Mihomo, TUN через sing-box, настройки маршрутизации и подписок, автоподбор сети, параллельные проверки серверов, автоматическое обновление подписок и диагностика. При необходимости Xray сохраняет исходные правила и DNS подписки, а Mihomo обслуживает совместимые транспорты.

**Android:** импорт подписок, подключение через Xray, настройки маршрутизации, обновление подписок и диагностика. Набор возможностей отличается от Windows.

## Бета-тест

Возможны ошибки совместимости и подключения. В сообщении об ошибке укажите ОС, выбранное ядро, последовательность действий и обезличенную диагностику. Не публикуйте ссылки подписок, ключи и другие данные доступа. Об ошибках можно сообщать в [Issues](https://github.com/sacoq/ZaNet.Connect/issues).

Клиент этой бета-ветки проверяет обновления в данном репозитории, включая опубликованные предварительные версии.

## Лицензии

В Windows-установщик включены уведомления о лицензиях и соответствующие исходники модифицированных VPN-ядер. Исходный код клиента в этом репозитории не публикуется.
